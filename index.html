Bulk Import Products

Fill the template in Excel or Google Sheets, copy the rows, and paste them below. Up to 100 products at a time.

1
Get the template

Open it in Excel / Google Sheets and fill one row per product.

2
Paste the rows here

Include the heading row. Excel/Sheets columns paste automatically.

3
Check and import

Rows with problems are listed — fix them in your sheet and paste again.

Column guide
  • name, price, stock, category, imageUrl, description — required.
  • originalPrice — the crossed-out "was" price. Leave blank for no discount.
  • colors — one color per ;, fields per |: name|hex|stock|photo URL. Hex, stock and photo can be left out: Black;White works, and the hex is filled in from the name.
  • stock — if every color has its own stock, the total is added up for you and the stock column can stay empty. If you type a different number, the color total wins and the row says so.
  • specifications — one per ; as Name:Value, e.g. Bluetooth:5.3;Battery:30 hours. Or just write a saved template's name (e.g. Smart Watch) to pull that whole set in.
  • brand, warranty, overview, active (yes/no), freeGift (yes/no) — optional.
  • A row whose name already exists is skipped, so you can paste the same sheet twice safely.
